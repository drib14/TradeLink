# TradeLink Administration & Moderation Portal

This directory contains the dedicated **TradeLink Campus Administration & SuperAdmin Dashboard** applications and contexts, separated from the student-facing client app.

## Contents
- **`src/pages/AdminDashboard.tsx`**: University of Cebu Moderation Desk (Student ID KYC Verifications, Listing Moderation, Prohibited Scanner, Campus Dispute Mediation, Audit Compliance Logs).
- **`src/pages/SuperAdminDashboard.tsx`**: System Configuration & Health Center (Feature flags, maintenance toggles, role provisioning, and telemetry).
- **`src/context/AdminContext.tsx`**: Platform administration state management and audit logging.
